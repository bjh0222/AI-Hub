# AI Hub 导航站 · 视觉设计系统规范 v1.0

**技术栈**：Next.js 14 App Router + React + TypeScript + Tailwind CSS（**不引入任何 UI 组件库**）
**主题**：深色「现代科技风」，单一暗色主题（聚焦自用工具站，不做浅色模式）
**实现方式**：所有令牌 = CSS 变量（`globals.css`）+ Tailwind 主题映射，组件全部手写 Tailwind 类名
**图元约束**：零位图。图标一律内联 SVG（`currentColor`），装饰性图形用 CSS 渐变/`radial-gradient`
**交付日期**：2026-10-09

> **关于色值的诚实标注**
> - 下表中**背景/边框/文本/强调色**是本次设计的**规范值**，可直接当唯一事实源使用。
> - 六个平台的品牌色是**近似示意值**：取自各产品公开的视觉印象并做过亮度调校，**不是官方品牌规范**，仅用于本自用站点的识别性区分。若将来要对外发布，必须换成各品牌官方提供的色值。
> - 表中所有对比度标注均为按 WCAG 2.1 相对亮度公式**实算**的结果（脚本见 §11），不是目测估计。

## 1. 色彩令牌

### 1.1 背景层（三级纵深）

| 角色 | CSS 变量 | Hex | Tailwind 用法 | 说明 |
|---|---|---|---|---|
| 页面底色 | `--bg-page` | `#0B0E14` | `bg-bg-page` | 带一丝蓝调的近黑，比纯黑更有科技感且更耐看 |
| 卡片 / 表面 | `--surface-1` | `#141922` | `bg-surface-1` | 平台卡片、列表项、面板 |
| 卡片悬停态 | `--surface-1-hover` | `#1B2230` | `hover:bg-surface-1-hover` | 悬停提亮一层 |
| 浮层 / 弹层 | `--surface-2` | `#1B2230` | `bg-surface-2` | Toast、下拉、Popover、黏性工具栏 |
| 内嵌凹槽 | `--surface-inset` | `#0E1219` | `bg-surface-inset` | 搜索输入框内部、多选操作栏 |
| 页面顶部光晕 | — | `#1E3A8A33` | `bg-[radial-gradient(...)]` | 见 §5.4 装饰渐变，纯 CSS |

页面级氛围：`bg-bg-page` 之上叠一层固定定位的径向渐变（蓝青双点光源），**不参与交互、`pointer-events-none`、`opacity` 固定**，避免动效开销。

### 1.2 边框

| 角色 | CSS 变量 | Hex | Tailwind 用法 | 对比度（vs 页面） | 说明 |
|---|---|---|---|---|---|
| 细边框 | `--border-subtle` | `#232B3A` | `border-border-subtle` | 1.36:1 | 卡片默认描边、纯装饰性分隔线 |
| 强边框 | `--border-strong` | `#58677D` | `border-border-strong` | **3.36:1** / 卡片上 3.06:1 | 控件轮廓（搜索框、次级按钮）、`kbd` 描边 |
| 悬停边框 | `--border-hover` | `#65769A` | `hover:border-border-hover` | **4.24:1** / 卡片上 3.87:1 | 控件悬停态标识 |
| 强调边框 | `--border-accent` | `#2563EB` | `border-border-accent` | **3.41:1**（卡片上） | 选中态；满足 1.4.11 |

**边框令牌的分工纪律**：`--border-subtle` 只用于**装帧**（卡片、区块、浮层），一旦某个边框要承担「这里是控件边界」或「现在是悬停态」的信息，**必须**换成 `--border-strong` 或 `--border-hover`。

> ⚠️ **本节修正记录（两轮）**：`--border-strong` 初值 `#334155` 实测仅 **1.87:1**、`--border-hover` 初值 `#3E4A61` 为 **2.31:1**，**均不满足 WCAG 1.4.11 的 3:1**。第一轮上调为 `#4A5568` / `#566279` 后复查仍差一点（在卡片底上分别只有 2.74:1 / 2.87:1，因为卡片底 `#141922` 比页面底更亮，同样的描边在卡片上对比度更低）。第二轮用脚本直接**反解**出同时满足「页面 ≥3:1 且卡片 ≥3:1」的最小提亮值，定为 `#58677D`（3.36 / 3.06）与 `#65769A`（4.24 / 3.87）。
>
> **教训**：边框令牌必须在**它实际出现的最亮背景**上验算，而不是只在页面底色上验算。§11 脚本因此对每个边框色同时输出 page 与 card 两个比值。

> **关于 1.4.11 的精确适用范围（别滥用）**：
> - 只有**当边框是该控件可识别边界的唯一线索**时，才要求 3:1。
> - **搜索框**的边界线索是 `--border-strong` 描边（3.06:1，卡片上）**+** 占位符文字 `text-fg-3`（5.97:1）**+** 放大镜图标（5.97:1），三者叠加足以识别控件，**合规**。注意 `--surface-inset (#0E1219)` 与页面底 `--bg-page (#0B0E14)` 只差 **1.04:1**，视觉上几乎不可分，**不能**把它当作合格的识别线索——这一点在初稿里被错判过。
> - **纯装饰性**分隔线与卡片描边（`--border-subtle` 1.36:1）**不受 1.4.11 约束**：卡片边界由表面色阶（`#141922` vs `#0B0E14`，1.19:1）+ `shadow-1` 共同表达，且卡片内所有功能信息的文字对比度均达标，移除描边不损失任何信息。
> - 结论：**「所有边框都要 3:1」是常见误读**。本系统的判定是：参与状态表达与控件识别的边框 = 3:1 硬要求；纯装帧边框 = 豁免。

### 1.3 文本三级

| 等级 | CSS 变量 | Hex | Tailwind 用法 | vs 页面 | vs 卡片 | 用途 |
|---|---|---|---|---|---|---|
| 一级 | `--text-1` | `#F2F6FC` | `text-fg-1` | 17.81:1 | 16.25:1 | 平台名、页面标题、金额数字 |
| 二级 | `--text-2` | `#A9B4C6` | `text-fg-2` | 9.23:1 | 8.42:1 | 描述文案、列表副标题、表单 label |
| 三级 | `--text-3` | `#8A97AD` | `text-fg-3` | 6.54:1 | 5.97:1 | 时间戳、计数、快捷键提示、占位符 |
| 反转文本 | `--text-on-accent` | `#FFFFFF` | `text-on-accent` | 5.17:1（在 `#2563EB` 上） | — | 主按钮文字 |
| 禁用文本 | `--text-disabled` | `#5A6478` | `text-fg-disabled` | 2.68:1（**豁免**） | — | 仅用于 `disabled` 元素，WCAG 明确豁免禁用态对比度 |

**层级规则**：同一卡片内文本等级**最多跨 2 级**（如平台名 `text-1` + 描述 `text-3`），不允许 `text-1` 与 `text-2` 同屏堆叠产生「都一样亮」的噪音。

> ⚠️ 初版 `--text-3: #6E7A90` 在卡片上仅 **4.07:1**，未达 AA，已上调为 `#8A97AD`。改动时请重跑 §11 脚本。

### 1.4 主强调色

| 角色 | CSS 变量 | Hex | Tailwind 用法 | 对比度 |
|---|---|---|---|---|
| 强调 500（主色） | `--accent-500` | `#4D9BFF` | `text-accent-500` / `border-accent-500` | 6.85:1（页面）· 6.25:1（卡片） |
| 强调 600（填充用） | `--accent-600` | `#2563EB` | `bg-accent-600` | 白字在其上 **5.17:1** |
| 强调 400（悬停提亮） | `--accent-400` | `#7BB4FF` | `hover:text-accent-400` | 8.23:1（卡片） |
| 强调 tint（选中底） | `--accent-tint` | `#1C2B41` | `bg-accent-tint` | 其上 `text-1` 13.16:1 · `accent-500` 5.06:1 |
| 焦点环 | `--focus-ring` | `#4D9BFF` | `outline-focus-ring` | 6.85:1（远超 3:1 要求） |

**分工**：`accent-500` 用于文字/图标/描边/焦点环；`accent-600` **只用于填充**（主按钮背景）；两者不混用，避免「蓝得不一样」的廉价感。

### 1.5 语义色

| 语义 | CSS 变量 | Hex | Tailwind 用法 | vs 卡片 | 使用场景 |
|---|---|---|---|---|---|
| 成功 | `--success` | `#34D399` | `text-success` | 9.16:1 | 「已复制」「已在 3 个标签页打开」 |
| 警告 | `--warning` | `#FBBF24` | `text-warning` | 10.55:1 | 「已收藏」星标高亮、粘贴板被拦截提示 |

### 1.6 平台品牌识别色（近似示意值 ⚠️）

| 平台 | 识别色（图标/文字用） | vs 卡片 | tint 底（16% 混色） | 填充色（白字用） | 白字对比 |
|---|---|---|---|---|---|
| ChatGPT | `--brand-openai: #2DD4A7` | 9.30:1 | `#183335` | `--fill-openai: #0B6B54` | 6.47:1 |
| DeepSeek | `--brand-deepseek: #7BA6FF` | 7.33:1 | `#222D41` | `--fill-deepseek: #2563EB` | 5.17:1 |
| Gemini | `--brand-gemini: #8AB4F8` | 8.36:1 | `#252F40` | `--fill-gemini: #1A73E8` | 4.51:1 |
| 通义千问 | `--brand-qwen: #A78BFA` | 6.47:1 | `#292940` | `--fill-qwen: #7C3AED` | 5.70:1 |
| Kimi | `--brand-kimi: #C4B5FD` | 9.54:1 | `#2D2F41` | `--fill-kimi: #7C3AED` | 5.70:1 |
| 智谱清言 | `--brand-zhipu: #6B96FF` | 6.24:1 | `#202B41` | `--fill-zhipu: #3B5BDB` | 5.67:1 |

**为什么品牌色比「印象中的品牌色」亮？**
原始品牌色（如 ChatGPT 绿 `#10A37F`）在 `#141922` 上只有 5.51:1，勉强可用；但一旦放进 16% 自身 tint 底上就掉到 **4.44:1，不达标**（智谱原色 `#4C6EF5` 更是只剩 3.86:1）。因此统一提亮一档到「浅色版」，保证**色块底上的图标/文字也过 AA**。表内已标注为示意值，替换成官方色前请重跑对比度。

**平台色的三种合法用法**（不允许出现第四种）：

```tsx
// ① 图标/微型文字：直接用识别色，保证在卡片与 tint 上都 ≥4.5:1
<svg className="text-[--brand-openai]" />
// ② 装饰块（平台首字母圆角方块）：识别色 16% 透明底 + 识别色前景
<div className="rounded-lg bg-[--brand-openai]/16 text-[--brand-openai]">C</div>
// ③ 实心填充（仅用于 ≤2 个字符的高对比标识）：fill 色 + 白字
<div className="rounded-lg bg-[--fill-openai] text-white">C</div>
```

**中文排版硬约束**：

1. **`tracking` 只对 ≥20px 的标题收负值**。中文全角字在 15px 及以下收紧会出现笔画粘连，正文与卡片标题一律 `tracking-normal`（`0`）。
2. `uppercase` 仅用于拉丁文小标签；中文没有大小写，强制 `uppercase` 无效但会继承 `letter-spacing`，故中文标签单独写。
3. 正文行高 ≥1.6 倍字号（15/24 = 1.60）；标题行高 1.33~1.45。
4. 平台名等专有名词**不做**首字母大写转换，原样输出（`DeepSeek`、`Kimi`、`ChatGPT`、`通义千问`）。
5. 描述文案中文标点用全角「，。、」，与拉丁词之间留一个半角空格（如 `DeepSeek 官方对话模型`）。

## 3. 间距 · 圆角 · 阴影 · 发光

### 3.1 间距（4px 基准栅格，只用这 11 档）

| 令牌 | px | Tailwind | 典型用途 |
|---|---|---|---|
| `space-0.5` | 2 | `p-0.5` `gap-0.5` | 图标与徽标内边距 |
| `space-1` | 4 | `p-1` `gap-1` | 复选框与文字之间 |
| `space-1.5` | 6 | `p-1.5` `gap-1.5` | 图标按钮内边距（视觉 32px） |
| `space-2` | 8 | `p-2` `gap-2` | 按钮内图标间距、标签内边距 |
| `space-3` | 12 | `p-3` `gap-3` | **卡片内边距（紧凑端）**、网格 gap（移动） |
| `space-4` | 16 | `p-4` `gap-4` | **卡片内边距（标准）**、网格 gap（平板） |
| `space-5` | 20 | `p-5` `gap-5` | 网格 gap（桌面 1280+） |
| `space-6` | 24 | `p-6` `gap-6` | 区块内边距、区块标题与内容间距 |
| `space-8` | 32 | `p-8` `gap-8` | 区块之间纵向间距（桌面） |
| `space-10` | 40 | `p-10` | 页面顶部留白、登录卡片内边距 |
| `space-16` | 64 | `py-16` | 空状态上下留白 |

**节奏规则**：纵向区块间距 = `40px`（移动）/ `32px`（`md`）；卡片到卡片 = `--grid-gap`（12/16/20）；卡片内「图标 → 标题」= 12px，「标题 → 描述」= 4px，「描述 → 底部操作行」= 16px。

### 3.2 圆角（6 档）

| 令牌 | 值 | Tailwind | 用途 |
|---|---|---|---|
| sm | 6px | `rounded-sm` | 复选框、微型徽标、快捷键 kbd |
| md | 10px | `rounded-md` | 按钮、输入框、列表项 |
| lg | 14px | `rounded-lg` | 平台首字母方块、Toast |
| xl | 20px | `rounded-xl` | **平台卡片**、搜索框、浮层 |
| 2xl | 24px | `rounded-2xl` | 黏性操作栏、登录卡片 |
| full | 9999px | `rounded-full` | 星标按钮、计数徽标 |

嵌套规则：**外圆角 = 内圆角 + 内边距**。卡片 `20px` + 内边距 `16px` → 内部元素最大 `rounded-md(10px)` 左右，禁止内层也用 20px（会出现「双圆角不平行」的廉价感）。

### 3.3 阴影（3 档 + 1 档禁用）

| 档位 | CSS 变量 | 值 | 用途 |
|---|---|---|---|
| 静置 | `--shadow-1` | `0 1px 2px 0 rgb(0 0 0 / 0.40)` | 卡片默认。深色主题下阴影几乎不可见，**主要靠边框区分层级**，阴影只是「贴地感」 |
| 悬浮 | `--shadow-2` | `0 4px 12px -2px rgb(0 0 0 / 0.50), 0 2px 4px -2px rgb(0 0 0 / 0.35)` | 卡片悬停、下拉 |
| 浮层 | `--shadow-3` | `0 16px 40px -8px rgb(0 0 0 / 0.62), 0 4px 12px -4px rgb(0 0 0 / 0.45)` | Toast、Modal、黏性工具栏 |

> 深色主题中阴影对比度天然低（`#000` 叠在 `#0B0E14` 上），因此**层级表达的主导手段是「表面色阶 + 边框 + 发光」三件套**，阴影是辅助。不要为了「看得出阴影」而把不透明度堆到 0.8，会糊成一团。

### 3.4 发光 Glow（3 档，本站点视觉签名）

| 档位 | CSS 变量 | 值 | 用途 |
|---|---|---|---|
| g1 微弱 | `--glow-1` | `0 0 0 1px rgb(77 155 255 / 0.20), 0 0 12px -2px rgb(77 155 255 / 0.20)` | 搜索框默认（暗示可交互）、已收藏图标底光 |
| g2 中等 | `--glow-2` | `0 0 0 1px rgb(77 155 255 / 0.35), 0 0 22px -2px rgb(77 155 255 / 0.32)` | **卡片悬停**、按钮悬停 |
| g3 强 | `--glow-3` | `0 0 0 1px rgb(77 155 255 / 0.55), 0 0 34px -4px rgb(77 155 255 / 0.48), 0 0 68px -12px rgb(77 155 255 / 0.30)` | **选中态**、搜索框聚焦、一键多开激活 |

**平台色 glow 变体**（卡片悬停时用自身品牌色，代入色值即得，无额外变量）：

```css
/* 用 color-mix 生成任意平台色的两档 glow */
.glow-brand-hover { box-shadow: 0 0 0 1px color-mix(in srgb, var(--brand) 35%, transparent),
                                0 0 22px -2px color-mix(in srgb, var(--brand) 32%, transparent); }
.glow-brand-active { box-shadow: 0 0 0 1px color-mix(in srgb, var(--brand) 55%, transparent),
                                 0 0 34px -4px color-mix(in srgb, var(--brand) 48%, transparent),
                                 0 0 68px -12px color-mix(in srgb, var(--brand) 30%, transparent); }
```

`color-mix()` 基线：Chrome 111+/Edge 111+/Safari 16.2+/Firefox 113+（2023 起），自用站点可放心用；**下方提供静态降级**（把品牌色写死成 rgb 三元组变量即可）。

```css
/* 静态降级：不依赖 color-mix，兼容到 Chrome 90+ */
[data-brand="openai"] { --brand-rgb: 45 212 167; }
[data-brand="deepseek"] { --brand-rgb: 123 166 255; }
[data-brand="gemini"]   { --brand-rgb: 138 180 248; }
[data-brand="qwen"]     { --brand-rgb: 167 139 250; }
[data-brand="kimi"]     { --brand-rgb: 196 181 253; }
[data-brand="zhipu"]    { --brand-rgb: 107 150 255; }

.glow-brand-hover  { box-shadow: 0 0 0 1px rgb(var(--brand-rgb) / .35), 0 0 22px -2px rgb(var(--brand-rgb) / .32); }
.glow-brand-active { box-shadow: 0 0 0 1px rgb(var(--brand-rgb) / .55), 0 0 34px -4px rgb(var(--brand-rgb) / .48),
                                 0 0 68px -12px rgb(var(--brand-rgb) / .30); }
```

**发光使用纪律**：**同屏可见的发光元素 ≤ 3 个**。网格里 6 张卡片若全部 hover 发光会变成「霓虹灯牌」，因此只有**指针实际悬停/选中**的那张发光，其余保持静置。

## 4. 组件规格

> 所有交互元素统一遵守：**视觉尺寸可以小于 44px，但点击热区必须 ≥44×44px**（用 `-m-1.5 p-1.5` 或伪元素扩展热区实现）。

### 4.1 模型卡片（四态）— 核心组件

**尺寸**：宽 `minmax(0,1fr)` 自适应；内边距 `p-4`（移动 `p-3`）；最小高度 **132px**（保证 4 列时文案不挤）。

**结构（从上到下）**：
```
┌──────────────────────────────────┐
│ [首字母方块 36×36]      [★] [☑]  │  ← 顶行：品牌标识左，星标+复选框右
│                                  │
│ ChatGPT                          │  ← Card Title 18/26 600 text-1
│ OpenAI 官方对话模型                │  ← Caption 13/20 text-3（最多 1 行 ellipsis）
│                                  │
│ [最近 · 3 分钟前]                 │  ← Micro 12/16 text-3（仅最近使用区显示）
└──────────────────────────────────┘
```

**四态精确规格**：

| 状态 | 背景 | 边框 | 阴影/发光 | 变换 | 文字 |
|---|---|---|---|---|---|
| **正常** | `bg-surface-1` | `1px solid var(--border-subtle)` | `shadow-1` | `translateY(0)` | `text-1` / `text-2` / `text-3` |
| **悬停** | `bg-surface-1-hover` | `1px solid color-mix(in srgb, var(--brand) 45%, transparent)` | `shadow-2` + `.glow-brand-hover` | `translateY(-2px)` + 品牌块 `scale(1.06)` | 标题色不变（**不加亮**，靠背景与发光对比即可） |
| **选中（多选）** | `bg-accent-tint` | `1px solid var(--border-accent)` | `glow-3` | `translateY(-2px)` | 标题 `text-1`；右上复选框变实心勾选 |
| **已收藏** | 同正常 | 同正常（悬停时同悬停） | 星标按钮 `bg-star-tint` + `--warning` 图标 + `glow-1` 局部 | — | 星标图标从描边 `text-3` 变实心 `text-warning` |

**四态叠加规则**（优先级从高到低）：`选中 > 悬停 > 已收藏 > 正常`。已收藏与选中**可同时存在**：底色走选中的 `accent-tint`，星标保留金色——两个语义各占「底」和「角落」，不冲突。

**已收藏 + 悬停**同时出现时，**星标保持金色**，卡片描边走品牌色（不叠加蓝色），避免三色混战。

```tsx
/* 卡片骨架（可直接用） */
<article
  data-brand={platform.id}
  aria-label={`${platform.name}，${platform.desc}`}
  className={[
    'group relative flex min-h-[132px] cursor-pointer flex-col justify-between rounded-xl p-4',
    'border border-border-subtle bg-surface-1 shadow-1',
    'transition-[background-color,border-color,box-shadow,transform] duration-base ease-emphasized',
    'hover:-translate-y-0.5 hover:border-[color-mix(in_srgb,var(--brand)_45%,transparent)]',
    'hover:bg-surface-1-hover hover:shadow-2 hover:glow-brand-hover',
    'motion-reduce:transition-none motion-reduce:hover:translate-y-0',
    selected && 'border-border-accent bg-accent-tint shadow-g3 hover:border-border-accent',
  ].filter(Boolean).join(' ')}
>
  <div className="flex items-start justify-between gap-2">
    <span className="grid h-9 w-9 place-items-center rounded-lg text-[15px] font-semibold
                     text-[color:var(--brand)]
                     bg-[color-mix(in_srgb,var(--brand)_16%,transparent)]
                     transition-transform duration-base ease-spring group-hover:scale-[1.06]">
      {platform.initial}
    </span>
    <div className="flex items-center gap-1">
      <FavStar active={fav} onToggle={...} />
      <MultiCheck checked={selected} onToggle={...} />
    </div>
  </div>
  <div className="mt-3">
    <h3 className="text-lg font-semibold tracking-[-0.01em] text-fg-1">{platform.name}</h3>
    <p className="mt-1 truncate text-[13px] leading-5 text-fg-3">{platform.desc}</p>

</article>
```

**键盘行为**：整卡是 `role="button"` 语义（外层 `<a>` 打开平台），`Enter` 打开、`Space` 切换多选（需在 `onKeyDown` 里 `preventDefault()` 阻止页面滚动），星标与复选框是**独立的可聚焦子控件**，Card 内 Tab 顺序为 `卡片 → 星标 → 复选框`。

### 4.2 搜索框

| 属性 | 值 |
|---|---|
| 高度 | 44px（`h-11`），移动端 40px（`h-10`） |
| 圆角 | `rounded-xl`（20px），移动端 `rounded-lg`（14px） |
| 背景 | `bg-surface-inset`（比页面更暗，形成「凹槽」感） |
| 边框 | 默认 `1px var(--border-strong)`；聚焦 `1px var(--border-accent)` |
| 内边距 | 左 16px（图标位），右 12px（快捷键提示位）；`pl-11 pr-20` |
| 占位符 | `text-fg-3`（5.97:1，达 AA），文案「搜索平台或模型…」 |
| 左侧图标 | 放大镜 18×18，`text-fg-3`，`absolute left-4`，`pointer-events-none` |
| 上限 | 输入内容最大 60 字符；`Enter` 打开首个结果 |

**清除按钮（有输入时出现）**：20×20 圆形，`text-fg-3` → 悬停 `text-fg-1` + `bg-surface-2`；**热区扩到 44×44**；`aria-label="清除搜索"`；出现动画 `opacity 0→1 + scale 0.9→1`，`150ms var(--ease-standard)`。

**快捷键提示（`kbd`）**：置于输入框右侧内嵌。Windows 优先显示 `Ctrl K`，macOS 显示 `⌘ K`。

```tsx
<kbd className="pointer-events-none absolute right-3 top-1/2 hidden -translate-y-1/2
                select-none items-center gap-0.5 rounded-sm border border-border-strong
                bg-surface-1 px-1.5 py-0.5 font-mono text-[11px] font-medium
                leading-4 text-fg-3 sm:inline-flex">
  {isMac ? '⌘' : 'Ctrl'} <span aria-hidden="true">+</span> K
</kbd>
```

> `kbd` 文字为 11px，视觉上是「装饰性提示」；但既然它渲染了文字，**仍按小文本要求 ≥4.5:1**——已用 `text-fg-3`（5.97:1）满足。另在搜索框上加 `aria-keyshortcuts="Control+K"`，并通过 `sr-only` 文案「按 Ctrl 加 K 聚焦搜索」向屏幕阅读器播报，不依赖视觉提示。
> 移动端（`<640px`）隐藏 `kbd`，因软键盘无此快捷键。

**聚焦态**（§6 有动画细节）：


### 4.3 收藏星标按钮

| 属性 | 值 |
|---|---|
| 视觉尺寸 | 28×28（`h-7 w-7`），圆角 `rounded-full` |
| 热区 | 44×44（外层包 `p-2 -m-2`） |
| 图标 | 内联 SVG 星形，16×16，`currentColor`，`fill` 与 `stroke` 双路径切换 |
| **未收藏** | `stroke: var(--text-3)`，`fill: none`，`stroke-width: 1.75` |
| **未收藏 · 悬停** | `stroke: var(--text-1)`，`bg-surface-2` |
| **已收藏** | `fill: var(--warning)`，`stroke: var(--warning)`，`bg-star-tint`，`glow-1` 局部 |
| 点击反馈 | 星形 `scale 1 → 1.25 → 1`（关键帧，`320ms var(--ease-spring)`），同时抛 Toast |
| `aria` | `<button aria-pressed={fav} aria-label={fav ? '取消收藏 ChatGPT' : '收藏 ChatGPT'}>` |

> **`aria-pressed` 与 `role="switch"` 不可同时使用**：二者语义重叠，同用会让部分屏幕阅读器重复播报（「开关，已按下」）。本系统统一用**切换按钮**模式（`aria-pressed`），不用 `role="switch"`。

```tsx
<button
  type="button"
  aria-pressed={fav}
  aria-label={`${fav ? '取消收藏' : '收藏'} ${name}`}
  onClick={(e) => { e.stopPropagation(); onToggle(); }}
  className="relative -m-2 grid h-11 w-11 place-items-center rounded-full
             text-fg-3 transition-colors duration-fast ease-standard
             hover:bg-surface-2 hover:text-fg-1
             focus-visible:outline-2 focus-visible:outline-offset-2 focus-visible:outline-focus-ring"
>
  <svg viewBox="0 0 24 24" width="16" height="16" aria-hidden="true"
       className={fav ? 'text-warning' : 'text-current'}
       fill={fav ? 'currentColor' : 'none'} stroke="currentColor" strokeWidth={1.75}>
    <path d="M12 3.6l2.6 5.27 5.82.85-4.21 4.1.99 5.79L12 16.88l-5.2 2.73.99-5.79-4.21-4.1 5.82-.85z"
          strokeLinejoin="round" />
  </svg>
</button>
```

**星标在卡片上的定位**：`top-4 right-4`，与复选框同行；星标在左、复选框在右（星标是「个人偏好」，复选框是「批量操作」，右侧留给操作类控件）。

### 4.4 多选复选框

| 属性 | 值 |
|---|---|
| 视觉尺寸 | 20×20（`h-5 w-5`），圆角 `rounded-sm`（6px） |
| 热区 | 44×44（`p-3 -m-3`） |
| **未选中** | `border: 1.5px solid var(--border-strong)`，`bg-transparent` |

```tsx
  <span aria-hidden="true"
    className="grid h-5 w-5 place-items-center rounded-sm border-[1.5px] border-border-strong
               bg-transparent transition-colors duration-fast ease-standard
               peer-hover:border-border-hover peer-hover:bg-surface-2
               peer-checked:border-accent-600 peer-checked:bg-accent-600
               peer-focus-visible:outline-2 peer-focus-visible:outline-offset-2
               peer-focus-visible:outline-focus-ring">
    <svg viewBox="0 0 24 24" width="13" height="13" fill="none" stroke="#fff" strokeWidth={2.5}
         strokeLinecap="round" strokeLinejoin="round"
         className={checked ? 'opacity-100' : 'opacity-0'}>
      <path d="M20 6L9 17l-5-5" />
    </svg>
  </span>
</label>
```

> **为什么自绘而不是 `accent-color`**：`accent-color` 无法控制圆角、尺寸与动画，且在深色主题下各浏览器渲染差异大。自绘 + `peer` 是纯 Tailwind 方案，无组件库依赖。

### 4.5 最近使用列表项

| 属性 | 值 |
|---|---|

| 内边距 | `px-3 py-2`，圆角 `rounded-md`（10px） |

| 键盘焦点 | 与悬停同款背景 + 焦点环 |
| 时间格式 | `<1 分钟前` → `刚刚`；`<60 分钟` → `N 分钟前`；`<24 小时` → `N 小时前`；否则 `M月D日` |

### 4.6 Toast 提示

| 属性 | 值 |
|---|---|
| 定位 | 固定**右上角**：`fixed top-4 right-4 z-50`；移动端改底部：`bottom-[calc(60px+16px+env(safe-area-inset-bottom))] left-4 right-4`（避开底部工具栏） |
| 尺寸 | `min-w-[280px] max-w-[380px]`，`rounded-lg`（14px），`px-4 py-3` |
| 背景 | 毛玻璃：`var(--glass-bg)` + `backdrop-filter`（右侧滑入的浮层最适合毛玻璃） |
| 边框 | `1px solid var(--border-subtle)`；左侧 3px 语义色竖条（`border-l-[3px]`） |
| 阴影 | `shadow-3` |
| 结构 | `[图标 18px] [标题 Body Strong] [× 关闭 32px 热区]` + 可选副文案 `Caption text-fg-3` |
| **成功** | 竖条 + 图标 `--success`，文案「已在 3 个标签页打开」 |
| **警告** | `--warning`，「浏览器拦截了 2 个弹窗，请允许本站弹出窗口」 |
| **错误** | `--danger`，「密码错误」 |
| **信息** | `--accent-500`，「已复制链接」 |
| 停留 | 默认 3200ms；带副文案的 5000ms；`hover` 暂停计时（`--dur-*` 无关，用 JS timer 暂停） |
| 堆叠 | 最多 3 条，纵向 `gap-2`；第 4 条挤掉最旧的 |
| `aria` | 容器 `role="region" aria-label="通知"`；**信息/成功用 `aria-live="polite"`，错误用 `aria-live="assertive"`**；每条 `role="status"`。**不要**给整个容器设 `aria-live`，否则同级更新会重复播报 |

**图标必须与颜色配对**（形状 + 颜色双通道），保证色觉障碍用户可辨：✓ 成功 / ⚠ 警告 / ✕ 错误 / ⓘ 信息。

### 4.7 空状态

三种场景，**统一版式、不同文案与动作**：

| 场景 | 触发 | 图标（内联 SVG 32×32 `text-fg-3`） | 主文案 `Body Strong text-fg-2` | 动作 |
|---|---|---|---|---|
| 无收藏 | 收藏区为空 | 描边星形 | 还没有收藏的平台 | 次级按钮「去挑选」（滚到平台网格） |
| 无最近记录 | 首次访问 / 已清空 | 描边时钟 | 还没有使用记录 | 无按钮，仅提示「打开任意平台后会自动记录」 |
| 搜索无结果 | `results.length === 0` | 描边放大镜 | 没有找到「{keyword}」 | 文字按钮「清除搜索」 |

**版式**：`flex flex-col items-center justify-center gap-3 py-16 text-center`；图标底可加一圈 `bg-surface-1` 圆形 64×64 弱化空荡感。**空状态不用插画位图**，一律内联 SVG 描边图标（`stroke-width: 1.5`，`currentColor`）。

### 4.8 一键多开操作栏

| 状态 | 表现 |
|---|---|
| **未选中任何卡片** | 降级为「紧凑条」：`sticky top-[64px]`，高 44px，只显示「已选 0 个 · 勾选卡片后可一键多开」，右侧按钮 `disabled`（`bg-surface-2 text-fg-disabled border-border-subtle`，`cursor-not-allowed`） |
| **已选 N 个** | 进入「激活态」：底部描边变 `--border-accent` + `glow-2`；左侧计数徽标 `bg-accent-600 text-white rounded-full px-2 py-0.5 text-xs tabular-nums`；主按钮变 `bg-accent-600 text-on-accent` |
| **主按钮文案** | 「一键多开（N）」，N≥2 时显示数字 |
| **打开中** | 按钮内左侧换 14px 旋转 spinner（`animate-spin`），文案「正在打开…」，按钮 `disabled`，`aria-busy="true"` |
| **结果反馈** | 成功 → 成功 Toast「已在 N 个标签页打开」；被拦截 → 警告 Toast「浏览器拦截了 M 个弹窗，请允许本站弹出窗口」，并在按钮旁常驻一行 `Caption text-warning` 补救提示 |
| **移动端** | 转为 `fixed bottom-0 inset-x-0` 底部工具栏，见 §7.2 |

**关键实现细节**：一键多开用 `window.open(url, '_blank')` 连续调用。除首个外若返回 `null` 说明被拦截，此时**不能静默失败**——必须走警告 Toast + 常驻提示。按钮点击后**立即**置 `aria-busy` 并禁用，避免重复触发。

## 5. 毛玻璃 · 阴影 · 发光的确切 CSS

### 5.1 毛玻璃 token

```css
:root {
  --glass-bg:        rgb(27 34 48 / 0.72);   /* 半透明浮层底 */
  --glass-bg-strong: rgb(27 34 48 / 0.86);   /* 文字密集的浮层，提高可读性 */
  --glass-bg-solid:  #1B2230;                /* 降级：完全不透明 */
  --glass-blur:      16px;
  --glass-saturate:  140%;
  --glass-border:    1px solid rgb(255 255 255 / 0.08); /* 顶部高光描边 */
  --glass-highlight: inset 0 1px 0 0 rgb(255 255 255 / 0.06); /* 内顶高光 */
}
```

### 5.2 毛玻璃实现（含降级）

```css
/* @layer components */
.glass {
  background-color: var(--glass-bg-solid);   /* ← 降级优先：先给不透明底 */
  border: var(--glass-border);
  box-shadow: var(--shadow-3), var(--glass-highlight);

  /* 单层 backdrop-filter，不要叠加 filter: blur()（会把内容一起模糊掉） */
  -webkit-backdrop-filter: blur(var(--glass-blur)) saturate(var(--glass-saturate));
  backdrop-filter:         blur(var(--glass-blur)) saturate(var(--glass-saturate));
}

/* 支持时才换成半透明底 */
@supports ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .glass { background-color: var(--glass-bg); }
}
```

**降级策略（三层，逐级判定）**：

| 环境 | 判定 | 表现 |
|---|---|---|
| 现代浏览器 | 支持 `backdrop-filter` | 半透明 + 模糊 + 饱和 |
| Firefox 旧版 / 部分安卓 WebView | 不支持 | 自动落到 `--glass-bg-solid` (`#1B2230`)，**不透明但完全可读**。因为 `background-color` 写在 `@supports` 之外，无需 JS |
| 用户开启「降低透明度」 | `prefers-reduced-transparency: reduce` | 强制不透明（见下） |

```css
@media (prefers-reduced-transparency: reduce) {
  .glass {
    background-color: var(--glass-bg-solid);
    -webkit-backdrop-filter: none;
    backdrop-filter: none;
  }
}
```

> **无位图替代方案（一般不需要）**：若某环境模糊效果明显掉帧，**不要**去做「截屏 + 模糊图片」的兜底（这违反零位图约束且维护成本高）。直接接受不透明降级即可——视觉损失远小于性能风险。

### 5.3 毛玻璃使用范围（严格限定）

| 允许 | 不允许 |
|---|---|
| 顶部搜索栏（滚动时吸顶） | 平台卡片（6 张同屏做模糊 → 合成层爆炸） |
| Toast | 大面积主内容区 |
| 黏性操作栏 / 一键多开栏 | 下拉菜单的每一项 |
| 移动端底部工具栏 | 登录卡片（居中浮层用纯色更有分量） |

**性能红线**：同屏 `backdrop-filter` 元素 **≤ 2 个**。`backdrop-filter` 会强制创建合成层，6 张卡片全上会掉到 30fps 以下。**平台卡片一律用纯色 `--surface-1`。**

### 5.4 装饰渐变（页面氛围，非毛玻璃）

```tsx
{/* 页面顶层氛围层：固定、不可交互、不参与动画 */}
<div aria-hidden="true" className="pointer-events-none fixed inset-0 -z-10 overflow-hidden">
  <div className="absolute -top-[280px] left-1/2 h-[560px] w-[860px] -translate-x-1/2
                  rounded-full bg-[radial-gradient(closest-side,rgb(37_99_235/0.18),transparent)]" />
  <div className="absolute -bottom-[220px] right-[8%] h-[420px] w-[620px]
                  rounded-full bg-[radial-gradient(closest-side,rgb(45_212_167/0.10),transparent)]" />
</div>
```

固定尺寸、`radial-gradient` 单色渐隐，`-z-10` 置于内容之下，**零 JS、零重绘开销**。

## 6. 关键动效（时长与缓动曲线）

### 6.1 缓动曲线（4 条，全站只用这 4 条）

| 名称 | CSS 变量 | cubic-bezier | 性格 | 用在哪 |
|---|---|---|---|---|
| Standard | `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | 快出缓停，中性 | 颜色/边框/透明度的普通过渡 |
| Emphasized | `--ease-emphasized` | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 起步快、收尾极缓 | **卡片悬停位移**、聚焦发光、布局位移 |
| Exit | `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | 缓慢起步、加速离开 | 元素消失、Toast 滑出、对话框关闭 |
| Spring | `--ease-spring` | `cubic-bezier(0.34, 1.40, 0.64, 1)` | 过冲回弹（y 取 1.40 > 1） | 星标点亮、勾选、图标缩放等**小元素**反馈 |

### 6.2 时长（5 档）

| 名称 | 值 | 用途 |
|---|---|---|
| Instant | 100ms | 颜色/背景即时反馈（hover 变色） |
| Fast | 150ms | 图标按钮、清除按钮出现 |
| Base | 200ms | **卡片悬停**、复选框勾选、焦点环 |
| Slow | 300ms | Toast 进出、列表项位移 |
| Slower | 420ms | 模态/登录卡片进出、区块入场 |

**规则**：位移越远、元素越大 → 时长越长；反之越短。**超过 420ms 的过渡一律不要**（自用工具站，等待感明显）。

### 6.3 四个关键动效的完整规格

#### ① 卡片悬停

```css
.platform-card {
  transition-property: transform, background-color, border-color, box-shadow;
  transition-duration: var(--dur-base);          /* 200ms */
  transition-timing-function: var(--ease-emphasized);
  will-change: transform;                         /* 仅 hover 时；或索性不加，现代浏览器足够 */
}
.platform-card:hover {
  transform: translateY(-2px);
  background-color: var(--surface-1-hover);
  border-color: color-mix(in srgb, var(--brand) 45%, transparent);
  box-shadow: var(--shadow-2), var(--glow-2);
}
.platform-card:hover .brand-tile { transform: scale(1.06); }
.brand-tile { transition: transform var(--dur-base) var(--ease-spring); }
```

- 位移 `-2px`：足够被感知，又不至于让网格看起来「在抖」。
- 进入用 `emphasized`、离开自动复用同一 transition（200ms）——**无需为 leave 单独写规则**，避免「进快出慢」的割裂。
- 品牌方块用 `spring` 微微过冲，制造「活物感」，是本站唯一的俏皮处。

#### ② 搜索框聚焦

```css
.search-field {
  transition: border-color var(--dur-base) var(--ease-standard),
              box-shadow var(--dur-slow) var(--ease-emphasized),
              background-color var(--dur-base) var(--ease-standard);
}
.search-field:focus-within {
  border-color: var(--border-accent);
  background-color: var(--surface-2);   /* 凹槽 → 抬升，暗示「进入了编辑态」 */
  box-shadow: var(--glow-3);
}
@keyframes search-pulse {
  from { box-shadow: 0 0 0 0 rgb(77 155 255 / 0.45); }
  to   { box-shadow: 0 0 0 12px rgb(77 155 255 / 0); }
}
.search-field:focus-within { animation: search-pulse 900ms var(--ease-emphasized) 1; }
```

一次性脉冲（900ms，只跑 1 次，不循环）——**循环脉冲会持续占用合成层，是耗电与掉帧常见来源**，禁止 `infinite`。

#### ③ 打开模型

```css
/* 卡片被激活（点击/Enter）*/
@keyframes card-activate {
  0%   { transform: scale(1); }
  45%  { transform: scale(0.97); }   /* 按下：轻微内缩，确认「收到了」 */
  100% { transform: scale(1); }
}
.platform-card[data-pressed='true'] { animation: card-activate 180ms var(--ease-standard) 1; }

/* 打开后本站自身做一次「让位」过渡（新标签页在浏览器层面打开，
   这里只做视觉确认，不做页面转场，避免与浏览器行为打架）*/
@keyframes handoff-out {
  to { opacity: 0.72; transform: scale(0.994); }
}
.grid--handoff { animation: handoff-out var(--dur-slow) var(--ease-exit) forwards; }
```

- 按下反馈 `180ms`，**必须在 200ms 内给出视觉响应**，否则用户会重复点击。
- 因为跳转发生在新标签页，本页做 `300ms` 的降透明度「让位」即可，回到本页时 `focus` 事件里还原（`0.72 → 1`，`200ms ease-standard`）。
- **禁用**入场时的整页淡入（`fade-in on load`）：自用工具讲究秒开，任何 >150ms 的入场遮罩都会被感知为「卡」。

#### ④ 一键多开反馈

```css
/* a) 操作栏从紧凑条 → 激活态 */
.actionbar {
  transition: border-color var(--dur-base) var(--ease-standard),
              box-shadow var(--dur-slow) var(--ease-emphasized),
              background-color var(--dur-base) var(--ease-standard);
}
.actionbar[data-active='true'] { border-color: var(--border-accent); box-shadow: var(--shadow-2), var(--glow-2); }

/* b) 计数徽标滚动变化：数字切换用纵向滑动，避免宽度突变 */
@keyframes count-in { from { transform: translateY(60%); opacity: 0; } to { transform: translateY(0); opacity: 1; } }
.count-badge > span { animation: count-in 160ms var(--ease-emphasized) 1; }

/* c) 每个被勾选的卡片依次亮起（stagger 40ms，上限 6 个 = 240ms） */
@keyframes pick-pulse {
  0%   { box-shadow: 0 0 0 0 color-mix(in srgb, var(--brand) 55%, transparent); }
  100% { box-shadow: 0 0 0 10px color-mix(in srgb, var(--brand) 0%, transparent); }
}
.card--picked { animation: pick-pulse 420ms var(--ease-emphasized) 1;
                animation-delay: calc(var(--pick-index) * 40ms); }

/* d) 点击「一键多开」：按钮内 spinner */
@keyframes spin { to { transform: rotate(360deg); } }
.spinner { animation: spin 700ms linear infinite; }   /* linear 是旋转唯一正确曲线 */
```

**stagger 上限**：`40ms × N`，`N` 封顶 6（即最多 240ms）。超过 6 个平台时后续不再延后，否则「选 12 个」会等半秒才亮完。

|---|---|---|---|

| 卡片按下 | transform scale | 180ms | standard |

## 7. 响应式断点策略

### 7.1 断点与栅格

| 断点 | 区间 | 卡片列数 | 容器内边距 | 网格 gap | 卡片内边距 | 最小卡片宽 | 变化要点 |
|---|---|---|---|---|---|---|---|
| 基础（移动） | 320–639px | **1 列** | 16px | 12px | `p-3` | — | 卡片改为横向布局（图标左、文字右），高度降到 88px；搜索框 40px；`kbd` 隐藏；工具栏移到底部 |
| `sm` | 640–767px | **2 列** | 16px | 12px | `p-4` | ~296px | 卡片回到纵向布局；`kbd` 显示 |
| `md` | 768–1023px | **2 列** | 24px | 16px | `p-4` | ~352px | 收藏区/最近使用改为左右两栏（`grid-cols-2`） |
| `lg` | 1024–1279px | **3 列** | 24px | 16px | `p-4` | ~314px | 区块纵向间距拉到 32px |
| `xl` | 1280–1535px | **4 列** | 32px | 20px | `p-4` | ~312px | 容器 `max-w-[1400px]` 居中 |
| `2xl` | ≥1536px | **4 列** | 32px | 20px | `p-5` | ~340px | **不再增列**，靠卡片变宽吸收多余空间（4 列是自用站的认知舒适上限） |

```tsx
<div className="mx-auto w-full max-w-container px-4 md:px-6 xl:px-8">
  <section className="grid grid-cols-1 gap-3 sm:grid-cols-2 md:gap-4 lg:grid-cols-3 xl:grid-cols-4 xl:gap-5">
    {platforms.map((p) => <PlatformCard key={p.id} {...p} />)}
  </section>
</div>
```

**为什么 `lg` 才 3 列、`xl` 才 4 列**：`md`(768–1023) 若放 3 列，每张卡只有 ~230px，平台名 + 两枚按钮会挤到换行。宁可 2 列大卡，也不做 3 列扁卡。

**断点用 `min-width` 移动优先**，全站**不出现** `max-width` 媒体查询，避免「桌面规则被移动规则覆盖」的调试地狱。

### 7.2 移动端工具栏处理

### 8.2 focus-visible 样式（全站统一）

```css
/* @layer base */
:where(a, button, input, textarea, select, summary, [tabindex]):focus-visible {
  outline: 2px solid var(--focus-ring);
  outline-offset: 2px;
  border-radius: inherit;   /* 焦点环跟随元素圆角，视觉不脱节 */
}

/* 卡片这类大元素：焦点环贴到卡片外沿 + 轻微发光，避免整块被描一圈显得笨重 */
.platform-card:focus-visible {
  outline: 2px solid var(--focus-ring);
  outline-offset: 2px;
  box-shadow: var(--shadow-2), var(--glow-2);
}

/* 移除默认焦点样式是禁止的；若必须重写，永远成对出现 */
:focus:not(:focus-visible) { outline: none; }   /* 鼠标点击不显示环，键盘才显示 */
```

**焦点规格统一为**：`2px solid #4D9BFF` + `offset 2px`（对比度 6.85:1，是 3:1 要求的 2.3 倍，在深色底上非常醒目）。

**键盘可达性清单**：

- 全站 **零 `tabindex="-1"`** 的交互元素；禁止 `outline: none` 裸写。
- **跳转链接**：`<a href="#platform-grid" className="sr-only focus:not-sr-only focus:absolute focus:left-4 focus:top-4 focus:z-50 focus:rounded-md focus:bg-surface-2 focus:px-4 focus:py-2">跳到平台列表</a>`，作为 `<body>` 首个子元素。
- **焦点陷阱（登录页）**：登录页只有 2 个可聚焦元素（密码框、按钮），Tab 循环天然闭合，**不需要 JS 焦点陷阱**。
- **焦点恢复**：Toast 关闭、多选操作栏收起后，焦点回到触发它们的元素（`ref.current?.focus()`）。
- **方向键**：卡片网格实现 roving tabindex（`↑↓←→` 在网格中移动，列数随断点变化），这是加分项；**若时间紧，可先只做 Tab 顺序**（左到右、上到下），且保证 Tab 顺序与视觉顺序一致。
- 快捷键 `Ctrl/Cmd + K` 聚焦搜索框；`Esc` 在搜索框内清空并失焦、在浮层内关闭浮层。

### 8.3 reduce-motion 处理

```css
@media (prefers-reduced-motion: reduce) {
  /* ① 位移动画彻底取消（不靠压时长，而是把 transform 从过渡属性里剔除） */
  .platform-card,
  .platform-card:hover,
  .platform-card:focus-visible,
  .recent-item:hover,
  .brand-tile,
  .count-badge > span {
    transform: none;
  }
  .platform-card {
    transition-property: background-color, border-color, box-shadow;
  }
  .brand-tile { transition-property: none; }

  /* ② 关键帧动画停用：脉冲、过冲、stagger、让位 */
  .search-field:focus-within,
  .platform-card[data-pressed='true'],
  .card--picked,
  .grid--handoff,
  .star-pop,
  .count-badge > span {
    animation: none;
  }

  /* ③ 只对「颜色/透明度/阴影」保留短过渡，保证 Toast 与按钮状态仍有因果感 */
  *, *::before, *::after {
    transition-duration: 100ms;
    scroll-behavior: auto;
  }
}
```

**三点刻意的取舍**：

1. **不对 `transform` 写 `transition-duration` 压缩**，而是把 `transform` 从 `transition-property` 里**移除**。压缩时长只是让位移变快——快速位移对前庭敏感用户**依然难受**；移除属性才是真正消除。
2. **不用 `* { animation-duration: 0.01ms }` 的全局写法**：它与上方逐条 `animation: none` 冲突（层叠上 `*` 的选择器优先级更低，但 `!important` 会赢），且会把 spinner 一起冻住。本系统**逐条显式声明**，可读且可控。
3. **过渡时长保留 `100ms` 而非 `0.01ms`**：全部归零会让 Toast 与按钮状态切换「瞬间跳变」，反而增加认知负担。100ms 既低于「被感知为动画」的阈值，又保留了最基本的因果感。

**JS 侧也要遵守**：

```ts
const reduceMotion = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
if (reduceMotion) { skipStagger(); skipPulse(); }
```

- Toast 的 3200ms 停留时间在 reduce-motion 下**延长到 5000ms**（没有滑入动画时，用户来不及反应）。
- `animate-spin` 的加载 spinner 在 reduce-motion 下**保留旋转**——它是「进行中」的语义载体，停转会让人以为卡死。改为 `opacity` 呼吸（`1 → 0.5 → 1`，1.4s）同样可行，二选一。

## 11. 附：对比度自检脚本

改动任何色值后，**必须**重跑本脚本再提交。放在仓库 `scripts/check-contrast.mjs`。

```js
// node scripts/check-contrast.mjs
const L = (hex) => {
  const c = hex.replace('#', '');
  const v = [0, 2, 4].map((i) => parseInt(c.slice(i, i + 2), 16) / 255)
    .map((x) => (x <= 0.03928 ? x / 12.92 : Math.pow((x + 0.055) / 1.055, 2.4)));
  return 0.2126 * v[0] + 0.7152 * v[1] + 0.0722 * v[2];
};
const ratio = (a, b) => {
  const [x, y] = [L(a), L(b)].sort((m, n) => n - m);
  return (x + 0.05) / (y + 0.05);
};
// 品牌色 @16% 混合到卡片底上（tint 底的真实算法）
const blend = (fg, bg, a) => {
  const F = fg.replace('#', ''), B = bg.replace('#', '');
  const m = [0, 2, 4].map((i) =>
    Math.round(parseInt(F.slice(i, i + 2), 16) * a + parseInt(B.slice(i, i + 2), 16) * (1 - a)));
  return '#' + m.map((x) => x.toString(16).padStart(2, '0')).join('');
};

const PAGE = '#0B0E14', CARD = '#141922', ELEV = '#1B2230';
const AA = 4.5, AA_LARGE = 3, NON_TEXT = 3;

const cases = [
  ['text-1 / card', '#F2F6FC', CARD, AA],
  ['text-1 / page', '#F2F6FC', PAGE, AA],
  ['text-1 / elevated', '#F2F6FC', ELEV, AA],
  ['text-2 / card', '#A9B4C6', CARD, AA],
  ['text-2 / page', '#A9B4C6', PAGE, AA],
  ['text-3 / card', '#8A97AD', CARD, AA],
  ['text-3 / page', '#8A97AD', PAGE, AA],
  ['text-3 / elevated', '#8A97AD', ELEV, AA],
  ['accent-500 / card', '#4D9BFF', CARD, AA],
  ['accent-500 / page', '#4D9BFF', PAGE, AA],
  ['accent-400 / card', '#7BB4FF', CARD, AA],
  ['white / accent-600 (按钮)', '#FFFFFF', '#2563EB', AA],
  ['white / fill-openai', '#FFFFFF', '#0B6B54', AA],
  ['white / fill-deepseek', '#FFFFFF', '#2563EB', AA],
  ['white / fill-gemini', '#FFFFFF', '#1A73E8', AA],
  ['white / fill-qwen', '#FFFFFF', '#7C3AED', AA],
  ['white / fill-kimi', '#FFFFFF', '#7C3AED', AA],
  ['white / fill-zhipu', '#FFFFFF', '#3B5BDB', AA],
  ['danger / card', '#FB7185', CARD, AA],
  ['success / card', '#34D399', CARD, AA],
  ['warning / card', '#FBBF24', CARD, AA],
  ['warning / star-tint', '#FBBF24', '#3E3722', AA],
  ['accent-500 / accent-tint', '#4D9BFF', '#1C2B41', AA],
  ['text-1 / accent-tint', '#F2F6FC', '#1C2B41', AA],
  ['border-accent / card (非文本)', '#2563EB', CARD, NON_TEXT],
  ['focus-ring / page (非文本)', '#4D9BFF', PAGE, NON_TEXT],
  ['border-strong / page (控件轮廓)', '#58677D', PAGE, NON_TEXT],
  ['border-strong / card (控件轮廓)', '#58677D', CARD, NON_TEXT],
  ['border-hover / card (悬停标识)', '#65769A', CARD, NON_TEXT],
];

// 平台色：在卡片上 + 在自己的 tint 底上，双重校验
const BRANDS = { openai: '#2DD4A7', deepseek: '#7BA6FF', gemini: '#8AB4F8',
                 qwen: '#A78BFA', kimi: '#C4B5FD', zhipu: '#6B96FF' };
for (const [k, c] of Object.entries(BRANDS)) {
  cases.push([`brand-${k} / card`, c, CARD, AA]);
  cases.push([`brand-${k} / 自身tint`, c, blend(c, CARD, 0.16), AA]);
}

let fail = 0;
for (const [name, fg, bg, need] of cases) {
  const r = ratio(fg, bg);
  const ok = r >= need;
  if (!ok) fail++;
  console.log(`${ok ? 'PASS' : 'FAIL'}  ${r.toFixed(2).padStart(6)}:1  (>=${need})  ${name}`);
}
console.log(fail === 0 ? '\n✅ 全部通过' : `\n❌ ${fail} 项未达标，请调整色值`);
process.exit(fail === 0 ? 0 : 1);
```

**实测结果（v1.0 定稿）**：29 项基础组合 + 12 项平台色组合 = **41 项全部 PASS**（`node sc_check.mjs` 退出码 0）。

## 12. 设计决策记录（为什么这么做）

| 决策 | 理由 | 代价 |
|---|---|---|
| 不做浅色模式 | 自用工具，单主题省一半维护量；深色更适合长时间盯屏 | 白天强光下体验略差 |
| `--border-strong` / `--border-hover` 比"看起来该有的"更亮 | 初值 1.87:1 / 2.31:1 不满足 WCAG 1.4.11 的 3:1；用脚本反解出最小合规值 | 边框比常见深色 UI 更显眼，需要靠 `--border-subtle` 承担大部分装帧任务 |
| 品牌色统一提亮一档 | 原色在 16% tint 底上跌破 4.5:1 | 与品牌官方视觉有偏差（已标注示意值） |
| 卡片用纯色不用毛玻璃 | 6 张卡同屏做 `backdrop-filter` 会掉帧 | 少一点「高级感」，换 60fps |
| 选中态用三通道（底+边+勾） | 单一通道在色觉障碍/高对比模式下失效 | 实现略繁 |
| 4 列为上限，不随 `2xl` 增列 | 自用站卡片是「入口」不是「数据格」，宽卡更好点 | 超宽屏两侧留白多 |
| 登录页错误不用抖动 | 动作敏感用户负面刺激；红字信息量更大 | 少一点「俏皮」 |
| 全局 reduce-motion 用 100ms 而非 0.01ms | 保留因果感，Toast 消失不突兀 | 严格标准派可能认为不够彻底 |
| 发光同屏 ≤3 个 | 防止网格变「霓虹灯牌」 | 需要 JS 控制 hover 互斥（用 CSS `:hover` 天然互斥即可） |
